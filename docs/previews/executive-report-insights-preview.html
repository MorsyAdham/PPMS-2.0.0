3 · Points to agree before building

Placement

  • One insights page after the station tables and before the issues report.
  • Nothing existing is moved or changed.

Formats

  • PDF and Word: this page.
  • Excel: a new "Insights" sheet in the same position.

Data

  • Every figure is computed from the same data and forecast as the dashboard, at the moment the report is generated.
  • Observations are written automatically from those figures.

Options

  • "Include production insights" switch, on by default.
  • Tell me what to add or drop from the page.
